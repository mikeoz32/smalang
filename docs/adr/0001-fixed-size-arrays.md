# ADR 0001: Фіксовані масиви за значенням

## Статус

Прийнято.

## Контекст

Мова наразі не має heap-алокатора, вказівників чи загального runtime-контейнера. Потрібен типізований масив, який зручно представляти в IR і безпосередньо розміщувати в пам'яті цільової архітектури. Рішення має залишати шлях до вкладених масивів, локального використання й майбутнього глобального сховища.

## Рішення

- Тип записується як `array[T, N]`. `N` — невід'ємна константа часу компіляції й частина типу; нульова довжина дозволена.
- Масиви зберігаються inline як послідовність елементів без runtime-заголовка, вказівника чи поля довжини. Вкладені масиви дозволені.
- Тип елемента має містити дані: цілі типи, `bool` або інший масив. Source-level `None` поки немає, а `unit` існує лише в IR; тому `unit` та винятки не можуть бути елементами і IR verifier також їх відхиляє.
- Довжина не змінюється; елементи можна змінювати через індекс.
- Присвоєння масиву, передавання його параметром і повернення з функції мають семантику значення: одержувач отримує незалежну копію елементів.
- Кожне оголошення масиву потребує ініціалізатора. Неявного нульового заповнення немає.
- Літерал має містити рівно `N` compile-time constant елементів. Ініціалізація масиву іншим масивом виконує копіювання.
- Індекс має тип `uint`. Відомий під час компіляції індекс поза діапазоном `0..N-1` є помилкою компіляції; динамічний вихід за межі породжує runtime-виняток через чинну модель винятків.
- Від'ємна індексація відкладена.
- Глобальні масиви потребують статичного сховища `.data`/`.bss`. Перший реалізаційний зріз обмежений локальними масивами у стекових кадрах; глобальні масиви будуть наступним кроком.
- Backend Linux x86_64 відхиляє масиви, чия довжина або inline-розмір не вміщується у signed 32-bit stack-frame addressing.
- Мовний тип `array[T, N]` не є слайсом: динамічної довжини, росту й heap-розміщення ця модель не вводить.

## Наслідки

- Розмір і розташування елементів можна визначити під час компіляції. Backend адресує елемент як базову адресу масиву плюс індекс, помножений на розмір елемента.
- Копіювання може коштувати `N * sizeof(T)` і є явним у семантиці навіть тоді, коли backend оптимізує фізичне переміщення.
- За відсутності нульового значення для типів оголошення потребують явної ініціалізації. Політика default values для типів залишається окремим рішенням.
- Динамічна перевірка меж додає внутрішній runtime-вид помилки, не вимагаючи нового користувацького синтаксису.
- Розмір типу відомий під час компіляції, тому надто великі для stack-frame addressing типи масивів відхиляються до генерації машинного коду.
- Глобальні змінні й статичне сховище не є передумовою стекового представлення локальних масивів; вони потрібні для наступного зрізу глобальних масивів.

## Відкладено

- Від'ємні індекси.
- Глобальні масиви й їхня статична ініціалізація.
- Неявні default values для типів.
- Масиви без явного ініціалізатора.
