# Feature Interview

1. Read `README.md`, `AGENTS.md`, and relevant code. Do not re-ask settled decisions.
2. Interview the user with one concise question at a time. Ask only about unresolved choices that materially affect scope, behavior, or design.
3. Create `plans/` if needed. Write a concise `plans/<feature-name>.md` covering the goal, agreed behavior, acceptance criteria, implementation steps, and verification.
4. Present the saved plan and wait for explicit approval. Do not edit product code before approval.
5. After approval, follow the plan. If a material decision changes, update the plan and get approval before proceeding.
